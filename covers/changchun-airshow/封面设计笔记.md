# DunrenW 视频封面设计笔记

> 给之后做封面时用：先读这份笔记、再看 `封面参考/` 里的图。
> 每做完一张封面，把它补进「已完成封面」；用户的新反馈补进「偏好」。

---

## 一、基本规格

- **尺寸**：3:4 竖版，导出 **2160×2880 PNG**，原生渲染（不要放大）。
- **存放**：本文件夹，命名 `封面_<标题>_3x4_2160x2880.png`；同一视频多方案加后缀，如 `封面_西湖日出_黎明_3x4_2160x2880.png`。
- **平台**：小红书 + **抖音**。信息流卡片只有约 300px 宽 —— **每版都要缩到 300px 宽检查**：标题能否一眼读出、画面主体是否清楚。发 **B站** 时另需一张 16:9 横版封面（首页卡片底部会叠播放量 / 时长条，重要文字放在下沿以上）。**横版规格**：3840×2160 PNG + 1920×1080 JPG（quality 93），命名 `封面_<标题>_横版_16x9_3840x2160.png` / `_1920x1080.jpg`；标题和色块底边 ≤ y1730（下 20% 留给播放量 / 时长）；用 360 宽的卡片模拟（底部渐变 + 左下播放量 + 右下时长）检查。横版沿用对应竖版的设计语言，不另起炉灶。
- **抖音主页格子的遮挡（必须避开）**：格子按 3:4 完整显示封面，但会叠加：
  - **左下角播放量**「▷ 5.8万」+ 底部约 28% 的压暗渐变 → 2160×2880 画布上 **x 0–1500、y 2450–2880 不放标题/重要元素**；
  - **左上角「置顶」黄标**（置顶作品）→ 约 x 0–700、y 0–500 不放重要元素；
  - 主页第一排是置顶的三条（目前：我们正在前进、此心安处是武威、夜之城），并排看要有整体感。
  - 做完用 `douyin_sim.py`（scratch 里写过：缩成 375 宽，画置顶标、播放量和底部渐变）模拟一下。
- **本仓库环境**（云端 Linux，2026-10-04 长春航展封面）：没有本机字体库，用 npm 上 @fontsource 的 woff2 分包（Barlow Condensed、Noto Serif SC = 思源宋体）经 fontTools 转 ttf；中文按字查所在分包逐字渲染。脚本在 `covers/changchun-airshow/scripts/`，源图需放成同目录 `p1.png`（彩烟）/ `p2.png`（本人 + 运输机）/ `p3.png`（J-20）。
- **素材**：`/Volumes/BackupDisk/Output/@dunrenw/` 下的视频成片。
  - 成片常有**烧录字幕**、**片头标题字**、片尾 **@dunrenW 水印**（兰州片左下角也有）→ 截图要挑干净的帧或裁掉。
  - 片尾常有日期/节气字卡（如西湖：「冬至 Dec 21 2024」），可作小字信息来源。
- **系列专属素材**：「此心安处」系列的标题是**用户朋友手写的书法**（「此心安处是武威」竖排），必须用原作，不要换字体。高清版是用户发的白底黑墨图（约 556×1200）：取 alpha = (228−灰度)/168，双三次放大后用 smoothstep(0.3–0.7) 重新收锐边缘，2160 下依然干净、保留飞白。铜奔马抠图（789×575 透明 PNG）也是用户提供的。`此心安處武威.psd` 文档只有 900×1200，图层分辨率不比这些高。
- **字体**（`~/Library/Fonts`）：2026-10-04 用户新装了一大批字体（约 1300 个文件，其中约 385 个能显示中文）。挑字体时先按片子气质筛几款，渲染样张对比再定，不要只用老几样。
  - **极影毁片辉宋**（粗、高反差、带电影感的宋体，繁简都全）用得最多，但**不必每次都用**。用户原话："字体以后不一定都用这个，有更好的也可以用"，按片子气质挑。
  - 新库里值得用的中文：**方正清刻本悦宋**（`FZQINGKEYUESONG_GB.TTF`，文气精致，小镇图像在用）、**老报宋**（`C300-老报宋.ttf`，旧报纸纪实感）、**苏新诗古印宋**（`C299-…`，斑驳旧印刷，适合怀旧 / 废墟题材）、**思源宋体** 全字重（`SourceHanSerifCN-*`）、汉仪大宋、方正粗雅宋、华康雅宋、全字库正宋体（细）、迷你简瘦金书、汉仪细秀体；手写类：李豪手迹、默陌信笺手写体、字语青梅硬笔、井柏然字体。
  - 新库里的英文：**Didot HTF**（L/M/B 多字重 + 斜体，时装杂志感，小镇图像用 `Didot-HTF-L24-Light-Ital_0.otf`）、Adobe Garamond Pro / Caslon Pro / Minion Pro（含斜体）、Trajan、Canela Bark、Bistro Serif/Sans、Adrift、Nomad、Moabhoers、Monthoers Vintage，以及大量手写体（Shepia、Sortdecai、Aaron、Florabella、Hurricane、Italianno…）。注意文件名有 `_0`、`.otf`/`.ttf` 混杂，先 `ls ~/Library/Fonts | grep` 确认。
  - 其他：电影海报字体（干笔毛笔，粗粝）、汇文正楷、CooperZhengKai、庞门正道标题体、万事全兴体、王强手写体。
  - **革命浪漫主义 / 年代感**（《我们正在前进》用过）：**草檀斋毛泽东字体**（`毛泽东字体-41970425e6dc.ttf`，毛体行草；「们」「进」显示为繁体「們」「進」）。标语、报头类：华康标题宋 W9（`DFPGB_S9.TTF`，数字也好看）、汉仪大宋 / 汉仪超粗宋、苏新诗古印宋。毛笔行书：叶根友毛笔行书简体2012版（简体、笔力粗、好认）、叶根友疾风草书、方正字迹-邢体草书（后两款草得厉害，缩小难认）。王漢宗魏碑體繁缺「们」「进」。
  - 英文：Barlow Condensed（各字重，窄体大写很好用）、Lora / Lora Italic（衬线、斜体）、Rajdhani、Lato。

## 二、用户偏好（来自真实反馈）

**喜欢 / 已采用**
- **可以直接复用好的设计语言**（用户 2026-10-04 明确说）：不需要刻意和已有封面做区隔。已有封面样式和收集的参考都是好案例，**适合这条片子就直接借用**它们的版式 / 设计语言。（早先西湖第一版被评"雷同"，原因是夜之城的拼贴模板硬套在西湖上、不合片子气质，并不是"不许复用"。）
- **字要好认**：行草类毛笔字（叶根友毛笔行书）被评"不太好辨认"。除非是此心安处那种指定的手写书法，标题优先用好认的字；用户喜欢**圆润温和**的字体（汉仪润圆 `HYRunYuan-*W` 很合适，霞鹜文楷 `LXGWWENKAIGBSCREEN.TTF` 也温和好认）。
- **字放在色块上**（小满第三版，用户提的）：满屏照片上直接放实心色块，色取自画面，字压在色块里——画面完整、字也清楚，不乱。
- **要灵动、别呆板**：规整的矩形色块、竖直对齐的方块字，放到主页里会显得像贴上去的标签（小满第四版"实际应用后有点呆板"）。灵动感主要靠后面叠一层飘逸的英文花体（参考 10 海边重庆）。但**不要倾斜摆放**、**不要手写体中文**（汉仪小麦体被换掉）——中文保持端正好认（霞鹜文楷合适），动感交给花体。色块不是必须的，用户说"怎么好看怎么来"。
- **少即是多**：副标题 / 第二句文案常被要求删掉（小满的「薰风初入弦」最终去掉）。默认只放一行主标题。
- **要有层次感**：等大、同色、同字号的元素显得平。用字号 / 字重分主次（主标题大而重，副标题小），色块一深一浅、互相叠压，加轻投影做出前后关系。
- **渐变要自然**：给照片续天空 / 加色调时，不要在短距离内拼一段纯色渐变（会出现色带、硬边）。让照片铺满，用**长距离、缓动、线性光混合**的半透明色调叠在原片天空上（见西湖日出横版第二版）。
- **乱是大忌**：小满第一版「大"满"压在布满荷叶的湖面 + 小"小" + 小字 + 立荷叶」被评"排版乱乱的"。字不要压在细碎、繁杂的画面上；元素少、留白多才高级。
- **满版大图 + 电影海报感**：西湖日出「黎明版」一次通过——一个镜头、天空延展成渐变、竖排白色标题、极少小字。
- **照片错落叠放 + 中间横排文字 + 大写英文地名**（夜之城，用户自己提的想法）。
- **水纹 / 倒影做底纹**（"波光粼粼倒映着城市"）。
- 红色**只用一处**做点缀。
- 中文标题常用 **极影毁片辉宋**，但按片子气质换字体更好（见「字体」）。
- 《我们正在前进》的封面要有**革命浪漫主义气质**（用户 2026-10-04）：毛体竖排标题，字体用户满意。但**纯黑背景不合适、整体太暗**，要借鉴**五六十年代宣传画**：明亮的米黄纸色 / 大红 / 金黄，平涂放射光芒（是图形，不是发光效果），照片做成印在纸上的质感。这条片子不受"红色只用一处"限制。

- **电影感**是用户最买账的方向：车窗书法版胜过墙上马影版（后者更像"画"）。主观视角、景深、暗调单光源、冷暖对比、"正在发生"的时刻都是加分项。
- **文字居中、拼图放左右**（我们正在前进，用户自己提的想法）。做成对称的"三联画"时要和夜之城的错落叠放拉开：左右照片规整竖排、两两对仗，标题竖排。
- 置顶行（我们正在前进 / 此心安处 / 夜之城）都是**暗调 + 暖色字**时最统一；大面积亮红的版本在这一排里会跳。

**不喜欢 / 被要求删掉**
- **小到看不清的字**：引文、地点名、账号 @DUNRENW、照片编号 01–04 都被删了。顶部一行极小的地名/经纬度可以留，其余尽量不加。
- **"新中式"套路堆砌**：团扇圆框 + 竖排题款 + 红印章 + 宣纸纹 + 光晕 → "太土了救命"。
- **用户本人可以出镜**（2026-10-04 用户明确说："可以放我本人的，如果合适的话"）。早先"右上角是我的照片，不用放了"只针对夜之城那张。合适时（背影眺望、徒步者与风景的关系是片子主题时）可以用，正脸近照仍谨慎。
- **背景太花**：整版彩色条纹（电影条码）被评"有意思但视觉有点乱"。概念可以留，但视觉要收——把它浓缩成一个颜色反而成立。
- 标题**不要堆地名**：「小镇图像」这种系列名 + 对应英文就够，不必再写"莫干山"。
- 截图只截半块招牌之类"有点呆"的裁法 → 有辨识度的元素要露全（「正宁路小吃夜市」整块牌匾）。
- **复杂边框 / 装饰线**：外框细线、照片金边、菱形端点、标题旁竖线 → "边框太复杂了，简洁一点"。拼图照片之间**也不要加黑线**，直接相接。
- **不清晰、松散的照片**：浅景深、主体发虚的人像（妈妈抱孩子）被换掉；大面积灰天空 + 细旗杆的空镜"不太美观"。人物主体要**放大、尽量居中**（举国旗的小朋友）。

### 提炼出的原则
1. **一张封面只讲一个想法**，先有概念再排版。例：夜之城 = 城市藏在倒影里；黎明 = 天空从夜到日。
2. **标题必须在 300px 缩略图里可读**，并且和画面有层次关系：压在接缝、被主体挡住一角、颜色取自画面、或在大留白里独立。
3. **密度二选一**：要么满版大图 + 极少字（春临 / 空山无人 / 生清暑 / 黎明版）；要么拼贴 + 强字（BEIJING / PAINTING / 夜之城）。不要两头都要。
4. **限色**：2–3 个主色；红色只点一处；标题色可直接从画面里取。
5. **中英混排**：中文为主角，英文是配角（窄体大写 / 衬线斜体 / 手写），不要喧宾夺主。
6. **小字只做肌理**，不承担必须读到的信息；这位用户偏好少放。
7. 避免套路符号（团扇、印章、宣纸、光晕、廉价渐变光效）。

## 五、制作流程备忘

1. 先问 / 先看：视频文案和字幕内容、片尾字卡、哪些人是用户本人。
2. 抽帧：先做整片 contact sheet 选镜头 → 用 ffmpeg **按时间戳**抽原尺寸帧（`-i 视频 -ss 秒数 -frames:v 1`，`-ss` 放在 `-i` 后面才精确）。用 `select=eq(n,N)` 会和缩略图编号对不上。镜头内用拉普拉斯方差挑最清晰帧。
3. 本机 Python 只有 PIL + numpy（没有 OpenCV / scipy），抠图靠手画多边形蒙版。
4. 先出 2 个方向的小预览对比，再精修一个；最后 2160×2880 原生渲染 + 300px 缩略图检查。
